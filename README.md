# MiixKey for Windows

Official MiixKey Windows 11 x64 installers, signed update manifests and release notes, published by **Miixpro**.

- [Latest release and installer](https://github.com/Miixpro/miixprokey-releases/releases/latest)
- [Online download guide](https://htu.miixpro.com/guide/miixkey-main-firmware.html#miixprokey-windows-app)

The desktop application is separate from device firmware. Version 0.9.2 and later can check for signed updates and ask before downloading or installing. Application source is maintained separately.
